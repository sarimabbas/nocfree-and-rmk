# Contribute

Small fixes, clear bug reports and tests on other computers are welcome.

Before a larger change, open an issue and describe the problem. Keep each pull request focused. Include what changed, why, and how you tested it. Read [TECHNICAL.md](TECHNICAL.md) for build commands and the firmware safety rules.

Run the checks for the code you change. For keyboard tests, list the computer, parts and connection modes you used.

For a problem with the app, use **Help → Export diagnostic logs**. Attach the ZIP to your issue. If export fails, describe what happened and add a screenshot.

Treat other people with respect. Keep discussion focused on the work.

Contributions use this project’s MIT license. Keep the license and credit for code from other projects.
