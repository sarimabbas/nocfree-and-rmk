# Contribute

Small fixes, clear bug reports and tests on other computers are welcome.

Before a larger change, open an issue and describe the problem. Keep each pull request focused. Include what changed, why, and how you tested it. Read [TECHNICAL.md](TECHNICAL.md) for build commands and the firmware safety rules.

Run the checks for the code you change. A build or a simulated test does not prove that a keyboard works. State which computer, keyboard parts and connection modes you tested. Do not upload factory software, private backups, device identifiers, passwords or signing files.

For a problem with the app, use **Help → Export diagnostic logs**. Review the ZIP and its screenshot before attaching it to an issue. Remove private information first. If export fails, say so and attach a screenshot with private details removed.

Treat other people with respect. Harassment, personal attacks and disclosure of private information are not welcome. Maintainers can close or remove contributions that do not follow this policy.

Your contribution uses this project's MIT license. Keep the license and credit for any code you copy from another project. Do not submit code you do not have permission to share.
