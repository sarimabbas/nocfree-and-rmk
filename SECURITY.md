# Report a security problem

Use [GitHub private vulnerability reporting](https://github.com/sarimabbas/nocfree-and-rmk/security/advisories/new) for a flaw that could expose data or make a firmware update unsafe. Do not post passwords, private backups or device identifiers in a public issue.

Include the affected version, the steps needed to reproduce the problem, and its effect. Review logs and screenshots before sharing them. Security fixes target the newest release. This early release has no guaranteed response time.
