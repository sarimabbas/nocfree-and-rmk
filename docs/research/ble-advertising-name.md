# BLE host advertisement name correction

Verified 2026-10-02 against pinned RMK `9607aedf343b17dd6b27307583ae80c4f728fbbd`. The installed full-left product name `NocFree AND RMK Left` is 20 ASCII bytes. RMK puts the entire product name in its legacy 31-byte host advertisement; flags, Battery/HID service UUIDs and keyboard appearance leave 16 bytes for that name. The Rust API does not truncate this configuration. [Host advertisement encoding](https://github.com/rmk-rs/rmk/blob/9607aedf343b17dd6b27307583ae80c4f728fbbd/rmk/src/ble/adv.rs), [product-name call path](https://github.com/rmk-rs/rmk/blob/9607aedf343b17dd6b27307583ae80c4f728fbbd/rmk/src/ble/mod.rs).

An independent host reproduction used the actual pinned trouble-host 0.8.0 `AdStructure::encode_slice` and the exact RMK host advertisement fields in a 31-byte buffer. The installed name returns `InsufficientSpace`; `NocFree RMK Left` is 16 bytes and returns `Ok(31)`. A 16-byte boundary name passes and a 17-byte name fails. This verifies the configuration/encoder failure, not an observed on-board advertisement trace or successful hardware pairing.

The correction changes only the left product-name literal to `NocFree RMK Left`. USB and Bluetooth share this product name, so USB also displays the shorter name after installation. VID/PID, device-derived serial, role features, scanner, radio configuration and storage addresses remain unchanged. RMK's storage schema hash depends on version/commit/features, not this literal; a name change does not trigger a schema migration. The right and receiver firmware need no change.

Before and after the edit, the repeatable reclaimed-layout harness passed host checks, formatting, all six production role/keymap cross-builds and diagnostics. The explicit full-left Mac recovery variant cross-built. A new candidate must still pass exact image guards, fresh left identity/readback and device-specific approval before transfer. The currently working split firmware is untouched. Host Bluetooth discovery, pairing, input, reconnect and wake acceptance are pending.
