# NocFree RMK Companion 0.1.1

First public preview for NocFree AND keyboards and Apple Silicon Macs.

## Included

- Guided RMK installation, factory backup/restore, recovery and pairing checks.
- Explicit Next-driven journeys with per-device state and connection requirements.
- Bundled ANSI/Mac RMK 0.1.1 firmware, with Vial remapping and optional Mac or Windows/Linux presets.
- Backlight brightness and persistence, battery idle sleep, and a local USB-power awake override.
- Diagnostic export with logs and an app-window screenshot when available.

## Download and use

Download the macOS arm64 ZIP, unzip it, and move NocFree RMK Companion to Applications. Back up each device’s original firmware before installing RMK. Keep those backups for factory restoration; factory firmware is not included.

## Validation and limits

The bundled application images were installed and verified byte for byte on the maintainer’s keyboard, and each current image reopened its recovery route. Wired and dongle split typing, cross-half Shift release, Bluetooth pairing/reconnection, brightness/remapping/persistence and idle wake were observed by the owner. These observations are not measured latency, current draw or endurance results.

- RMK split BLE can leave a held key repeating after the right half is powered off. This is a known upstream-path limitation; release held keys before switching a half off. If it occurs, reconnect the half and press/release the affected key; reconnect the host route if needed.
- Battery percentages use provisional calibration.
- This preview targets ANSI NocFree AND hardware. Other layouts or hardware revisions are not independently accepted.
- Apple Silicon only. Tested locally on macOS 27; the macOS 13 deployment target does not establish acceptance on older systems. Intel, Windows and Linux Companion binaries are not included.
- Installation on a separate clean Mac remains untested. Report permission or journey failures using Help → Export diagnostic logs…, and review the exported screenshot and logs before sharing them.
